# Cinq leçons sur la psychanalyse — Fiche de lecture complète

Site statique en français consacré à l’ouvrage de Sigmund Freud, adapté du dossier fourni. Il contient le dossier intégral, les trois parcours pédagogiques et leurs versions imprimables A4. Les analyses et les vérifications documentaires rapportées restent attribuées à la source.

## Consulter le site

Le fichier d’entrée est `index.html`. Le site utilise uniquement HTML, CSS et JavaScript natifs, sans compilation ni dépendance. Il peut aussi être ouvert directement depuis le disque, hors connexion pour son contenu principal.

Les liens vers des ressources documentaires externes nécessitent une connexion. Le portrait fourni et les documents originaux sont inclus dans le dépôt. Les conditions de réutilisation du portrait ne sont pas renseignées ; aucune licence générale n’est ajoutée aux documents ou aux images.

## Hébergement GitHub Pages

Dans les paramètres du dépôt, ouvrir **Pages**, choisir **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`. Le fichier `.nojekyll` permet de servir directement les fichiers statiques.

## Contenu

- `index.html` : accueil et exploration des cinq leçons.
- `dossier.html` : intégralité du dossier fourni.
- `primaire.html`, `secondaire-inferieur.html`, `secondaire-superieur.html` : trois fiches conservées intégralement.
- `imprimer-*.html` : versions individuelles A4 avec toutes les réponses.
- `assets/` : présentation, interactions et image locale.
- `originaux/` : copies à l’identique des documents sources et de leur trace de provenance.
- `integrite.json` : empreintes SHA-256 des copies originales.
- `CONTROLES.md` et `LIRE_MOI.txt` : contrôles et notice de la première livraison locale, antérieure à la demande de publication sur GitHub.

Les recommandations pédagogiques ne constituent pas des prescriptions officielles. Les concepts présentés sont ceux du texte historique de Freud et ne sont pas exposés comme des conclusions scientifiques actuelles incontestées.
